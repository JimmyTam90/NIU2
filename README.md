# niu-us-landing-page

Next.js 14.2.35 (App Router, JavaScript, Tailwind 3), standalone Vercel deployment. Install with `npm install`, build with `npm run build`.
Set `NEXT_PUBLIC_SITE_URL` to the deployed domain. Affiliate URLs live only in `lib/affiliate-links.js`; product data in `lib/products.js`.
Logo: `public/logo.png` (attached original); `public/logo-trimmed.png` is the same artwork with transparent margins cropped for the header and footer.
Favicons: `public/favicon.ico`, `public/favicon.png`, `public/apple-touch-icon.png`.
